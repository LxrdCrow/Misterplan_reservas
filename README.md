# MisterPlan — Gestión de reservas

Aplicación web para la gestión de reservas de alojamiento,
desarrollada como prueba técnica para MisterPlan.

## Objetivo

Implementar una API REST en PHP nativo para gestionar reservas,
utilizando MySQL para la persistencia de datos.

El proyecto prioriza la seguridad, la validación de entradas,
la separación de responsabilidades y la calidad del código.

## Tecnologías

- PHP nativo
- MySQL 
- Twig
- JavaScript
- Git
